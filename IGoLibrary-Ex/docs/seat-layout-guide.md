# 真实布局选座

抢座和全域捡漏的黑名单编辑器默认显示场馆真实布局。座位、桌面、柱子、文字和其他设施按照接口坐标排列；座位之间的空白保留为原始通道和间隔。

## 地图操作

- 使用滚轮或滚动条浏览；空白区域可以左键拖动，座位上可以用中键拖动。地图获得焦点后，也可以按住空格拖动。
- 使用放大、缩小、100%、适应宽度和全图按钮；Ctrl（macOS 为 Command）加滚轮围绕指针缩放。
- 长场馆的全图比例可以低于 10%；手动缩放下限随全图比例调整，到达下限后继续缩小会保持原比例，不会反向放大。
- 在“定位座位号”中输入座位号并按回车或点击定位。重名或多个匹配结果需要选择具体座位，结果同时显示座位标识。
- 定位只移动视口和高亮座位，不自动勾选。搜索过滤、定位和本次选择互相独立。
- 筛选输入框旁的下拉框可选择“场馆布局视图”和“列表视图”，默认使用场馆布局。手动选择后自动保存，启动时恢复，抢座与黑名单工作区共享此偏好。切换视图不会刷新接口或丢失选择、收藏和标签；布局异常触发的自动列表降级不会修改保存的偏好。

## 状态和筛选

座位顶部的状态色条区分空闲、平台已选、有人、暂离。本次本地勾选使用强调色描边和勾号，定位使用另一层高亮边框。状态详情可通过座位提示查看。

左下角的金色星星表示收藏，右下角的蓝底书签表示有标签；两者可同时显示。常用缩放（47% 及以上）下角标保持 12～18 DIP 的屏幕尺寸。低于 47% 时使用金色圆点和蓝色方块，避免遮住邻座；放大后恢复完整图形。悬停可查看收藏状态和完整标签。

“平台已选”来自接口的座位状态，不代表本次勾选，也不代表当前账号预约了这些座位。不能用颜色判断座位是否属于当前账号。

地图筛选会淡化不匹配的座位并禁止点击，不移动或移除座位和设施；列表筛选则隐藏不匹配项。已勾选座位不会因筛选而取消，批量标签操作仍包含已勾选但被过滤的座位。清除筛选后可以继续操作它们。

“仅看空闲座位”只在列表视图显示和生效。切回场馆布局后，即使保留了该勾选状态，也不会淡化或禁用被占用座位；按座位号或标签输入的筛选条件在两种视图中仍然有效。

抢座目标和黑名单均允许选择当前被占用的座位。任务执行时仍以原有业务规则判断空闲状态。

## 保存与刷新

抢座选座仍需确认完成后提交目标。关闭窗口会放弃本次勾选，但已经保存的收藏和标签不撤销。

黑名单按场馆维护草稿，“确认保存”后生效。切换场馆不会清空草稿，已经不在布局中的黑名单记录仍会保留并允许手动移除。全域捡漏任务运行时禁止修改。

同一场馆刷新保留缩放和视口，并在内容边界变化后校正位置。刷新失败保留最后一次成功加载的地图和草稿，同时显示失败提示。切换到其他场馆后，过期响应不会覆盖当前场馆。

抢座工作区和场馆信息页在绑定场馆期间暂时禁用刷新，绑定结束后恢复，避免刷新打断已更新底层场馆的绑定流程。新绑定仍会取消旧场馆尚未完成的刷新。

## 不完整或异常布局

桌子、入口、图片柱子、窗和书架使用用户提供的官方 PNG，嵌入应用资源并在本地共享加载，不需要联网下载。类型映射为：`2=桌子`、`3=入口`、`6=图片柱子`、`7=窗`。`type=8` 有名称时保留原始文字（包括“柱”和方向文字），空名称时显示书架图片；不会把所有“柱”都替换成图片。资源位于 `Assets/SeatLayout/`。

尚未确认含义的设施保留中性图形，其提示显示原始类型，不擅自命名。设施图片和文字均不能用于选座。

旧响应只有座位坐标时仍可显示地图。缺失场馆宽高由实际元素推导；边界小于实际坐标时不会裁掉有效内容。

重复座位标识、多个座位重叠、超过 10,000 个元素或任一坐标轴跨度超过 4,096 格时，会提示并切换列表。重复标识的勾选会同步，因为它们对应同一业务座位。以上限制只影响展示，不减少后台任务的候选座位。

视图模式保存到现有应用设置的 `ui.seatWorkspaceListView` 字段，不新增数据库表或迁移。缩放、视口和筛选状态仍只保留在当前工作区会话。地图不会自动轮询接口；刷新沿用现有按钮和请求流程。
