# 远程蓝牙签到详细使用指南

本文档说明如何在 IGoLibrary-Ex 中使用远程蓝牙签到，包括使用前准备、独立签到授权、iBeacon 参数填写、场馆配置保存、再次使用以及常见问题处理

> [!IMPORTANT]
> 远程签到只能为当前已经存在的预约执行签到，不能代替抢座、占座或明日预约
>
> 远程签到使用独立的 `wechatSESS_ID`，不能复用普通登录已经使用过的授权链接。每次需要重新授权时，都必须重新扫码获取一条新的授权链接

## 📌 功能流程概览

完整流程如下：

```text
完成普通登录
    ↓
已有一条可以签到的当前预约
    ↓
锁定当前预约所在场馆
    ↓
重新扫码获取签到专用授权
    ↓
确认签到账号并获取服务端允许的 iBeacon UUID
    ↓
填写 Major、Minor 和 GCJ-02 经纬度
    ↓
保存当前场馆配置
    ↓
点击“立即远程签到”
```

第一次使用通常需要完成全部步骤。以后再次对同一个场馆签到时，软件会自动加载之前保存的场馆配置，一般只需要恢复或重新获取签到授权、刷新信标并确认参数仍然有效

## ✅ 使用前准备

开始前请确认以下条件全部满足：

1. 已使用正确的微信账号完成普通登录
2. 该账号已经有一条当前可签到的座位预约
3. 软件锁定的场馆与当前预约所在场馆一致
4. 已准备好场馆实际使用的 iBeacon `Major`、`Minor`
5. 已准备好场馆实际位置的 GCJ-02 纬度和经度


## 🏛️ 第一步：完成普通登录并锁定预约场馆

1. 打开 IGoLibrary-Ex
2. 进入 `账户与场馆` 页面
3. 按主 README 中的“获取 Cookie”说明完成普通登录
4. 确认页面显示已授权状态
5. 点击 `更换当前场馆...`
6. 选择当前预约所在的场馆
7. 点击 `保存并锁定场馆`
8. 确认软件能够查询到当前预约，并核对场馆和座位信息

> [!WARNING]
> 锁定场馆必须与当前预约所在场馆一致。如果预约在 A 馆，但软件锁定的是 B 馆，签到前检查会失败

## 🔐 第二步：获取签到专用授权

进入 `远程签到` 页面，在页面上方找到 `签到专用授权` 区域

### 获取授权前的注意事项

1. 必须使用一条重新扫码得到的新授权链接
2. 不要粘贴刚才用于普通登录的授权链接
3. 授权链接中的 `code` 通常只能消费一次
4. 如果提示链接已使用、已过期或没有返回 `wechatSESS_ID`，请重新扫码，不要反复提交原链接
5. 应使用与普通登录、当前预约相同的微信账号进行签到授权

### 方法一：复制授权链接到电脑

1. 在 `远程签到` 页面扫描页面内的微信授权二维码
2. 扫码后进入“我去图书馆”授权页面
3. 点击微信页面右上角的 `...`
4. 点击 `复制链接`
5. 通过手机 QQ、微信文件传输助手或其他方式，把链接发送到电脑
6. 在电脑上复制这条链接
7. 保持 IGoLibrary-Ex 停留在 `远程签到` 页面并激活软件窗口
8. 软件检测到剪贴板中的新授权链接后，会自动开始获取远程签到授权
9. 如果没有自动识别，把链接粘贴到输入框，然后点击 `解析并获取授权`


### 方法二：局域网快传签到授权

1. 确认手机和电脑连接在同一个局域网内
2. 在 `远程签到` 页面点击 `局域网快传签到授权`
3. 如果系统弹出防火墙提示，请允许软件监听局域网
4. 弹窗会显示局域网提交页二维码和手机访问地址
5. 使用手机微信扫描弹窗中的二维码，打开手机提交页
6. 手机提交页中会显示第二个 `微信授权二维码`
7. 在微信内长按识别该授权二维码
8. 如果无法长按识别，可以先截图，再使用微信扫一扫识别截图
9. 进入“我去图书馆”授权页面后，点击右上角的 `...`
10. 点击 `复制链接`
11. 返回刚才的手机提交页
12. 点击 `点击粘贴链接`
13. 如果微信浏览器禁止读取剪贴板，就长按输入框手动粘贴
14. 点击 `发送到电脑`
15. 提交成功后，电脑端会自动解析授权并刷新远程签到页面


## 👤 第三步：确认签到账号

获取签到授权后，页面会显示 `提交前置状态`，其中包括：

- 锁定场馆
- 当前预约
- 签到账号
- 信标状态

请重点核对 `签到账号`，如果账号不正确：

1. 点击 `清除签到授权`
2. 使用正确的微信账号重新扫描授权二维码
3. 获取新的授权链接并重新授权

## 📡 第四步：刷新并选择 iBeacon UUID

点击 `刷新信标` 后，软件会验证签到授权并从服务端获取当前预约区域允许的 iBeacon UUID

授权成功时，软件也会自动尝试获取一次账号和 UUID。如果页面已经显示账号信息和允许的 UUID，说明自动刷新成功；仍然可以手动点击 `刷新信标` 再次确认

### 只返回一个 UUID

如果服务端只返回一个 UUID，软件会自动选中该 UUID

仍然需要填写与这个实际信标对应的 Major、Minor 和位置坐标，不能只保存 UUID

### 返回多个 UUID

如果服务端返回多个 UUID，软件不会替你猜测，而是要求手动选择：

1. 查看场馆实际 iBeacon 广播信息或部署配置
2. 找到与当前场馆、楼层或预约区域对应的 UUID
3. 在下拉列表中选择对应 UUID
4. 再填写这个 UUID 对应的 Major 和 Minor

### 没有返回 UUID

如果提示 `当前预约区域未返回可用的 Beacon UUID`，请依次检查：

1. 是否真的有一条当前预约
2. 签到账号是否正确
3. 当前预约是否已经取消、过期或结束
4. 服务端是否为该预约区域配置了 iBeacon
5. 签到授权是否仍然有效

`刷新信标` 只会获取服务端允许的 UUID，不会扫描电脑或手机附近的蓝牙设备，也不会返回 Major、Minor

## 🧭 第五步：准备 Major、Minor 和 GCJ-02 坐标

### 参数说明

| 参数 | 允许范围或格式 | 参数来源 |
| --- | --- | --- |
| Beacon UUID | 标准 UUID 格式 | 服务端允许列表，并与场馆实际信标核对 |
| Major | `0`～`65535` | 场馆实际 iBeacon 广播或部署配置 |
| Minor | `0`～`65535` | 场馆实际 iBeacon 广播或部署配置 |
| GCJ-02 纬度 | `-90`～`90` | 场馆实际位置的 GCJ-02 坐标 |
| GCJ-02 经度 | `-180`～`180` | 场馆实际位置的 GCJ-02 坐标 |

### 如何获取 Major 和 Minor

需要在场馆现场使用 BrightBeacon 扫描周围的蓝牙设备，从 iBeacon 广播中读取 UUID、Major 和 Minor

使用 BrightBeacon 时可以按下面的步骤操作：

1. 到达实际签到区域附近，并打开手机蓝牙
2. 打开 BrightBeacon，按系统提示授予扫描蓝牙设备所需的权限
3. 开始扫描并等待周围的 iBeacon 设备出现
4. 回到 IGoLibrary-Ex 的 `远程签到` 页面，点击 `刷新信标`，记下服务端允许的 UUID
5. 在 BrightBeacon 的扫描结果中找到 UUID 与服务端允许列表一致的设备
6. 打开对应设备的详细信息，记录它广播的 Major 和 Minor
7. 回到 IGoLibrary-Ex，把 UUID、Major、Minor 填入当前场馆配置
8. 核对 GCJ-02 坐标后点击 `保存场馆配置`

如果附近设备很多，应优先使用 UUID 与服务端允许列表进行匹配，而不是只根据设备名称或信号强度判断。一般签到信标的 Major、Minor 数值可能比较大，可以作为辅助筛选线索，但这不是固定规则，不能因此排除数值较小的实际信标

> [!WARNING]
> 有用户观察到部分服务端可能没有严格校验 Major 和 Minor，但我未实际检验过。如果你实在不知道或者没有条件获取真实的 Major和 Minor，那你随便填了试试，不保证能行

### 如何准备 GCJ-02 坐标

需要填写场馆实际签到区域对应的 GCJ-02 纬度和经度。最推荐使用奥维互动地图查看，也可以使用高德开放平台的坐标拾取器

#### 方法一：使用奥维互动地图（推荐）

奥维互动地图在中国大陆境内默认使用 GCJ-02 显示标签、轨迹点和图形点的经纬度，并会在坐标旁标注 `GCJ-02`

手机端可以按下面的步骤操作：

1. 安装并打开奥维互动地图
2. 搜索学校或图书馆名称，也可以在到达图书馆后使用手机定位
3. 将地图放大到实际签到区域，尽量选择信标所在区域或靠近预约区域的位置
4. 在该位置创建一个标签
5. 点击刚创建的标签
6. 点击标签名称，进入 `标签设置` 页面
7. 点击 `经纬度及高度`
8. 确认坐标旁显示 `GCJ-02`，并使用十进制度数值
9. 记录纬度和经度，填入 IGoLibrary-Ex

奥维官方说明可参见：[地图坐标系说明](https://www.ovital.com/131322-2/comment-page-1/)和[查看标签经纬度](https://www.ovital.com/131956-2/)

如果人在图书馆现场，可以使用手机当前位置创建标签，但室内定位可能漂移几十米。应等待定位稳定，并检查定位点是否落在图书馆实际建筑或签到区域内；如果明显漂到马路、其他建筑或校园外，应手动把标签移动到正确位置

#### 方法二：使用高德坐标拾取器

高德开放平台使用 GCJ-02 坐标系，可以通过[高德坐标拾取器](https://lbs.amap.com/tools/picker)获取坐标：

1. 打开高德坐标拾取器
2. 搜索学校或图书馆名称
3. 放大地图并点击实际签到区域
4. 复制页面显示的坐标结果
5. 将纬度、经度分别填入 IGoLibrary-Ex

高德坐标系说明可参见：[高德开放平台服务使用什么坐标体系](https://lbs.amap.com/faq/advisory/others/39838)

> [!WARNING]
> 高德坐标拾取器目前可能只向游客和未认证开发者显示小数点后两位。两位小数的误差可能达到约 1 公里，不适合作为签到坐标。如果页面只显示类似 `116.39,39.90` 的结果，也可以测试能否使用，不能请改用奥维互动地图

#### 注意经纬度填写顺序

地图工具经常按照下面的顺序显示坐标：

```text
116.397590,39.908776
```

通常代表：

```text
经度,纬度
```

而 IGoLibrary-Ex 界面的输入顺序是：

```text
GCJ-02 纬度：39.908776
GCJ-02 经度：116.397590
```

#### 不建议直接使用的坐标来源

| 来源 | 原因 |
| --- | --- |
| 百度地图普通坐标 | 国内默认通常是 BD-09，不是 GCJ-02 |
| 手机原始 GPS 或照片 EXIF | 通常可能是 WGS-84，不一定是 GCJ-02 |
| Google Earth | 一般使用 WGS-84 |
| 只保留两位小数的坐标 | 精度略低，可能无法准确表示场馆位置 |
| 度分秒格式坐标 | IGoLibrary-Ex 输入框使用十进制度数值 |

百度地图默认使用的 BD-09 是在 GCJ-02 基础上再次处理的坐标，不能直接作为 GCJ-02 填入。相关说明可参见[百度地图坐标转换文档](https://lbsyun.baidu.com/docs/android?title=androidsdk%2Fguide%2Ftool%2Fcoordinate)


## 💾 第六步：保存当前场馆配置

填写完成后，点击 `保存场馆配置`


## 🚀 第七步：执行远程签到

点击签到前，建议再次核对：

- 普通登录仍然有效
- 锁定场馆与当前预约一致
- 签到账号与预约账号一致
- 当前预约仍然存在并处于可签到状态
- UUID 与实际信标一致
- Major、Minor 来自实际信标
- 坐标为正确的 GCJ-02 纬度、经度
- 页面提示当前场馆配置已保存

满足条件后，点击 `立即远程签到`

## 🎉 签到成功后的显示

签到成功后，页面底部会显示类似信息：

```text
验证成功 · 场馆名称 · 座位名称 · 签到 2026-07-10 10:00:00 · 有效至 12:00:00
```

## 🔁 下次打开软件如何再次使用

### 同一个场馆、UUID 没有变化

如果下次打开软件后仍然锁定同一个场馆：

1. 软件会根据场馆 `LibraryId` 自动加载已保存的 UUID、Major、Minor 和坐标
2. 如果勾选过 `记住签到授权` 且授权尚未到期，软件会恢复签到授权
3. 页面可能显示 `已加载安全保存的签到授权，等待服务端验证`
4. 点击 `刷新信标` 验证账号和服务端允许的 UUID
5. 如果原 UUID 仍在允许列表中，保存的配置继续有效，不需要重新填写
6. 确认当前预约与锁定场馆一致后，可以直接点击 `立即远程签到`

即使不手动点击 `刷新信标`，点击签到时软件仍会重新获取允许 UUID 并校验。但为了提前发现账号、授权或 UUID 变化，建议签到前手动刷新一次

### 同一个场馆、UUID 已经变化

刷新信标后，如果原 UUID 不再位于服务端允许列表中：

1. 原配置会被标记为需要重新保存
2. 如果只返回一个新 UUID，软件会自动选中
3. 如果返回多个 UUID，需要手动选择实际信标
4. Major 和 Minor 会被清空
5. 重新填写对应的 Major、Minor
6. 核对坐标后重新保存场馆配置

### 切换到另一个场馆

1. 回到 `账户与场馆` 页面
2. 锁定新的预约场馆
3. 返回 `远程签到` 页面
4. 软件会尝试加载新场馆自己的配置
5. 如果从未保存过该场馆，需要重新填写并保存完整参数
6. 即使两个场馆返回相同 UUID，也不会自动复制另一个场馆的 Major、Minor 和坐标


## 🔘 按钮无法点击时如何检查

| 按钮 | 无法点击的常见原因 |
| --- | --- |
| `解析并获取授权` | 普通登录尚未完成，或者已有签到操作正在执行 |
| `局域网快传签到授权` | 普通登录尚未完成，或者已有签到操作正在执行 |
| `刷新信标` | 没有签到授权、普通登录失效，或者已有操作正在执行 |
| `保存场馆配置` | 未锁定场馆、没有允许 UUID、UUID 未选择、参数缺失或越界 |
| `立即远程签到` | 普通登录失效、未锁定场馆、没有签到授权、配置未保存或正在执行其他操作 |

`立即远程签到` 按钮是否可用不代表一定存在有效预约。点击后软件还会重新查询预约；如果没有预约，仍然会停止并提示

## 🛠️ 常见问题

### 提示“未能从链接中提取 32 位 code”

当前粘贴的内容不是有效授权链接，或者链接复制不完整

处理方法：

1. 重新打开微信授权页面
2. 使用右上角 `...` 中的 `复制链接`
3. 不要只复制页面显示的一小段文字
4. 将完整链接重新粘贴到软件

### 提示“该授权链接已被普通登录或远程签到处理”

说明这条链接已经被当前软件用于普通登录或远程签到

处理方法：重新扫描二维码，获取一条全新的授权链接。不要继续重试旧链接

### 提示“授权响应未返回 wechatSESS_ID”

常见原因：

- 链接已经被使用
- 链接已经过期
- 扫码流程没有正确完成
- 服务端没有返回签到会话

处理方法：重新扫码并复制新链接

### 签到账号不是当前预约账号

1. 点击 `清除签到授权`
2. 确认微信当前登录的是正确账号
3. 重新扫码获取新授权链接
4. 再次确认姓名、学校和脱敏学号

### 提示“当前没有可签到的预约”

软件在点击签到后重新查询，没有找到当前预约

请检查：

- 预约是否已经取消
- 预约是否已经到期
- 普通登录账号是否正确
- 普通登录 Cookie 是否仍然有效
- 是否需要先完成座位预约

### 提示“当前预约与锁定场馆不一致”

1. 记下当前预约所在场馆
2. 回到 `账户与场馆` 页面
3. 选择预约所在场馆
4. 点击 `保存并锁定场馆`
5. 返回远程签到页面核对场馆配置

不同场馆按 `LibraryId` 保存独立配置，切换场馆后不要直接沿用页面上未确认的参数

### 提示“服务端允许的 Beacon UUID 已变化”

1. 点击 `刷新信标`
2. 重新选择实际信标 UUID
3. 重新获取并填写 Major、Minor
4. 核对 GCJ-02 坐标
5. 点击 `保存场馆配置`
6. 再执行签到

### 提示“签到授权已到期”或“签到授权已失效”

签到授权会被自动清除，普通登录通常仍然保留

处理方法：

1. 保持普通登录有效
2. 在远程签到页面重新扫码
3. 获取新的签到专用链接
4. 完成授权并刷新信标

### 提示“签到请求的结果未知”

出现网络超时或连接中断时，软件无法判断服务端是否已经收到签到请求，因此不会自动重试

> [!CAUTION]
> 不要立即再次点击签到。第一次请求可能已经成功，重复提交可能产生不可预期结果

正确处理方法：

1. 先通过“我去图书馆”官方页面或其他可靠方式核对实际签到状态
2. 确认第一次请求没有成功后，再决定是否手动重试
3. 如果无法确认，优先避免重复提交

### 点击“清除签到授权”后会发生什么

- 清除内存中的签到授权
- 清除系统安全凭据中保存的签到授权
- 不会清除普通登录 Cookie
- 不会删除按场馆保存的 UUID、Major、Minor 和坐标配置

重新授权后，同一个场馆之前保存的配置仍然可以继续加载和验证
